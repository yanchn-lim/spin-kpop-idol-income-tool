Using normal mutations, this is the highest reachable combination when a card is limited to four mutation slots and fusion ingredients are consumed.

Slot-safe crafting order

  1. Radiant + Corrupted + Moonlit + Abyssal → fuse Corrupted + Abyssal into Void.
  2. Add Crimson → fuse Radiant + Moonlit + Crimson into Blossom.
  3. Add Radiant and Moonlit → fuse Moonlit + Blossom + Radiant into Starlight.
  4. Add Corrupted and Abyssal → fuse them into Glitched.
  5. Add Crimson → fuse Void + Crimson + Glitched into Hollow.
  6. Add Candy and Crimson → fuse them into Velvet.
  7. Add Crimson. Final mutations: Starlight, Hollow, Velvet, and Crimson.

No step exceeds four slots. Starlight + Hollow + Blossom + Cosmic is stronger on paper, but it cannot be crafted on one card under this limit.
